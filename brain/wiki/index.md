# Brain Index

One line per file. Agents read this first to know where to look.

## wiki (what the team knows)
- about-me.md — founder profile, niche, tone, accounts, goals, routine
- content-calendar.md — upcoming posts, reel ideas, what has been posted
- startup-context.md — project status, what's being built, decisions made

## raw (captured as-is)
Files land here unedited: voice memo transcripts, pasted notes, raw research.
Name format: YYYY-MM-DD-topic.md

## outputs (what Vision made)
Everything Vision produces with a date in the filename.
Name format: YYYY-MM-DD-type-topic.md
Examples: 2026-11-21-reel-script-ai-trend.md, 2026-11-21-blog-weekly-roundup.md
